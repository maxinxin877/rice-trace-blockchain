# Docker + Nginx 部署指南

后端（Spring Boot）、MySQL、Redis、Nginx 全部通过 Docker Compose 一键启动。

---

## 1. 目录准备

```
qukuailian/
├── Dockerfile
├── docker-compose.yml
├── nginx/nginx.conf
├── sql/init.sql          # 首次启动自动建库建表（仅空数据卷时执行）
└── frontend/dist/        # 前端构建产物（放这里，Nginx 挂载；git 已忽略）
```

前端（Vue 等）构建后把 `dist` 目录放到 `frontend/dist`：

```bash
# 例：前端项目构建
cd ../frontend && npm run build
# 把 dist 复制到后端项目
cp -r dist <项目路径>/frontend/dist
```

## 2. 启动

```bash
cd <项目路径>
docker compose up -d --build
```

启动后：

| 服务 | 地址 | 说明 |
| --- | --- | --- |
| Nginx | http://localhost:80 | 前端页面 + `/api/` 反向代理到后端 |
| 后端 API | http://localhost:8080 | 直连调试用 |
| MySQL | localhost:3306 | root / root123456 |
| Redis | localhost:6379 | 无密码 |

## 3. 配置项（docker-compose.yml 环境变量）

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| `SPRING_DATASOURCE_URL/USERNAME/PASSWORD` | compose 内置 | MySQL 连接 |
| `SPRING_DATA_REDIS_HOST/PORT` | redis:6379 | Redis 连接 |
| `BCOS_ENABLED` | false | 是否启用真实 FISCO BCOS（false 时上链模拟成功，便于演示） |
| `BCOS_CONFIG_FILE` | /app/bcos/config.toml | SDK 配置文件（镜像内已含模板） |
| `BCOS_CONTRACT_ADDRESS` | 空 | 合约地址，搭好链后回填 |

### 接入真实链（可选）

1. 按 `docs/FISCO_BCOS搭建指南.md` 搭链并部署 `Evidence` 存证合约。
2. 把证书放进 `src/main/resources/bcos/conf/`（构建时自动拷入镜像 `/app/bcos/conf`）。
3. 修改 compose：

```yaml
    environment:
      BCOS_ENABLED: "true"
      BCOS_CONTRACT_ADDRESS: "0x2c5b1f0f0c1a5f8e6b7c..."
```

4. 重新构建：`docker compose up -d --build`

> 注意：SDK 需要能访问链的 20200 channel 端口。节点在宿主机时，`bcos/config.toml` 的 `peers` 填宿主机 IP；节点也在容器时，把节点加入同一网络或填容器名。

## 4. 常用操作

```bash
docker compose ps                 # 查看状态
docker compose logs -f app        # 看后端日志
docker compose logs -f nginx      # 看 nginx 日志
docker compose down               # 停止（保留数据卷）
docker compose down -v            # 停止并清空数据卷（MySQL 会重新执行 init.sql）
```

## 5. 常见问题

- **MySQL 初始化脚本没生效**：`init.sql` 只在数据卷首次创建时执行；改脚本后需 `docker compose down -v` 重建。
- **改代码不生效**：`docker compose up -d --build` 重新构建镜像。
- **CORS 报错**：生产环境走 Nginx 同源（`/api/` 反代），前端请求写相对路径 `/api/...` 即可；开发环境后端已放开跨域。
- **想改端口**：改 compose 中 `ports` 映射即可。
