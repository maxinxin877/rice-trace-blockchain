# 数据库初始化指南（qukuailian）

本指南用于在本地 MySQL 中创建后端所需的 `qukuailian` 数据库（17 张表 + 种子数据），
并完成后端连接配置对齐。全程约 2 分钟。

---

## 0. 前提

- MySQL 8.0 已安装并启动（本机服务名 `MySQL80`，端口 3306）
- 本机 root 密码：**`1234`**（如与你的实际密码不同，把下面所有 `-p1234` 换成你的密码）
- 初始化脚本：`sql/init.sql`（项目根目录下）


PowerShell 不支持 `<` 重定向，用管道：

### 执行成功标志

命令无报错输出即为成功（最多有一行 `Warning: Using a password on the command line interface can be insecure.`，可忽略）。

## 5. 后端连接配置对齐（必须）

`src/main/resources/application-dev.yml` 中数据库密码要与你本机一致（当前是 `123456`，本机实际是 `1234`）：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/qukuailian?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: 1234      # ← 改成你本机的 MySQL root 密码
```

改完后启动 `QukuailianApplication`，跑 `pwsh scripts/smoke-test.ps1` 验证全流程。

---

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| `ERROR 1045 Access denied` | 密码不对，把 `-p1234` 换成你实际的 root 密码 |
| `ERROR 1049 Unknown database` | init.sql 没执行成功，重新执行 |
| 重复执行 init.sql | 会 **DROP 后重建**所有表，已有业务数据会被清空（开发阶段无妨） |
| 执行后中文乱码 | 库表均为 utf8mb4，一般不会出现；出现则确认连接参数带 `characterEncoding=utf8` |
| MySQL 不在 3306 端口 | 命令行加 `-P 端口号`，并同步修改 `application-dev.yml` 的 url |
