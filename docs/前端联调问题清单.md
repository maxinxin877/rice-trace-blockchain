## 联调约定

1. 开发环境使用 `VITE_USE_MOCK=true`，联调环境使用 `VITE_USE_MOCK=false`。
2. 页面只调用 API 模块，不直接调用 Axios。
3. 前端页码 `page` 由 API 模块转换为后端 `pageNo`。
4. 业务 ID 必须取上游主数据，不允许页面构造另一套批次号。
5. 写操作成功后重新查询列表，避免只修改页面内存状态。
